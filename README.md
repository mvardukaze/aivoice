# aivoice — ქართული სინთეზური ხმები

საკუთარი, ლიცენზიით სუფთა ქართული ხმების შექმნა [Piper](https://github.com/OHF-Voice/piper1-gpl)-ით:

1. **საბაზო მოდელი** — ქართული ისწავლა 296 ადამიანის ხმაზე (Common Voice, CC0), დაწყებული ინგლისური LJSpeech-იდან (საჯარო საკუთრება).
2. **ხმის შემქმნელი** — რამდენიმე ხმის ნარევით იქმნება ახალი ხმა, რომელიც არცერთ რეალურ ადამიანს არ ეკუთვნის.
3. **ცალკე ხმა** — ნარევიდან იწვრთნება მსუბუქი, ფიქსირებული Piper-ის ხმა (`.onnx`), რომელიც ბიბლიოთეკაში ჩადგება.

ყველაფერი იმართება ვებ-პანელიდან (`./aivoice serve`) ან ბრძანებებით (`./aivoice help`).

## დასაწყისი

```bash
git clone https://github.com/mvardukaze/aivoice.git && cd aivoice
./install.sh
./aivoice serve            # → http://127.0.0.1:8200 → ⚙ პარამეტრები → მოდელები → ↓ ჩამოტვირთვა
```

კოდი საჯაროა ([GitHub](https://github.com/mvardukaze/aivoice), GPL-3.0). მოდელები ორ რეპოზიტორიაშია:

| | რა არის | წვდომა |
|---|---|---|
| **საჯარო** [mvarduka/aivoice-voices](https://huggingface.co/mvarduka/aivoice-voices) | ხმის შემქმნელი **80 სინთეზური ხმით** („v3 საჯარო“), საჯარო საბაზო checkpoint ახალი ხმების წვრთნისთვის, მზა ხმები, ლექსიკონი | **ანგარიშის გარეშე** |
| **პირადი** [mvarduka/aivoice-models](https://huggingface.co/mvarduka/aivoice-models) | საბაზო მოდელები და შემქმნელი Common Voice-ის **ნამდვილი** ხმებით, ხარისხის მონაცემები (საბაზოს გასაუმჯობესებლად) | HF ანგარიში + ავტორის წვდომა + Read token |

„⚙ პარამეტრები → მოდელები → ↓ ჩამოტვირთვა“ (ან `./aivoice models pull`) ჯერ საჯაროს ჩამოტვირთავს, მერე — პირადს, თუ token გაქვთ.
**ახალი ხმების შესაქმნელად** მონიშნეთ „+ საბაზო checkpoint-ები“ — საჯაროში სინთეზური ხმებით საბაზო checkpoint-იც არის,
ასე რომ ნარევიდან ხმის წვრთნა („წვრთნა“ → Kaggle) პირადი წვდომის გარეშეც მუშაობს.

ამის შემდეგ **მაშინვე** შეგიძლიათ: მზა ხმებით გახმოვანება (ემოციები, გრძელი ტექსტი → MP3/WAV + SRT),
ხმის შემქმნელში ნარევების აწყობა და შენახვა, ლექსიკონი. **აკრძალულია** მოდელებით ნამდვილი ადამიანის ხმის მიბაძვა და მოტყუება.

დანარჩენი ანგარიშები საჭიროა მხოლოდ შესაბამისი ფუნქციისთვის:

| რისთვის | ანგარიში | ფასი |
|---|---|---|
| ახალი ხმის შექმნა ნარევიდან („წვრთნა“) | **Kaggle** token — kaggle.com → Settings → API → *Generate New Token* (+ ტელეფონის ვერიფიკაცია GPU-სთვის) | უფასო (30 GPU-სთ/კვირა) |
| საბაზო მოდელის შექმნა / გაუმჯობესება | **Google Cloud** (იხ. [ქვემოთ](#google-cloud--საბაზო-მოდელის-წვრთნა)) + `./aivoice models pull --base --data` | ფასიანი, ≈ $0.9/სთ (საცდელი კრედიტი $300) |
| Common Voice-ის ნედლი არქივის ჩამოტვირთვა ([საკუთარი მონაცემები](#საკუთარი-მონაცემები-common-voice)) | **Mozilla Data Collective** API key | უფასო |
| თქვენი ხმების/ნარევების ატვირთვა საერთო რეპოზიტორიაში | Hugging Face **Write** token (ავტორის მიცემული ჩაწერის უფლებით) | უფასო |

## დაყენება

**საჭიროა:** macOS (Apple Silicon) ან Linux · ~10 GB დისკზე (+ ~10 GB, თუ ხმებს ამზადებთ) · ინტერნეტი.
Windows-ზე — WSL2 (Ubuntu) და იგივე ინსტრუქცია.

```bash
git clone https://github.com/mvardukaze/aivoice.git
cd aivoice
./install.sh              # პანელი + ხმის შემქმნელი
./install.sh --training   # + ახალი ხმების მომზადება (torch, ~3 GB) — საჭიროა „წვრთნის“ ჩანართისთვის
./aivoice serve           # → http://127.0.0.1:8200
```

macOS-ზე `install.sh` Homebrew-ით აყენებს Python 3.12-ს, ffmpeg-ს და espeak-ng-ს (Homebrew: https://brew.sh).

### პირველი გაშვება

პანელი პირველად გაიხსნება **„⚙ პარამეტრებზე“** — დაყენების ოსტატი აჩვენებს, რა არის მზად და რა აკლია:

1. **მონაცემების საქაღალდე** — სად შეინახოს დიდი ფაილები (ნაგულისხმევი `~/aivoice-data`).
2. **ანგარიშები** — გასაღებები პირდაპირ პანელში ჩაიწერება (უკან არასოდეს ჩანს, ინახება მხოლოდ ამ კომპიუტერზე):
   - **Kaggle** — უფასო GPU წვრთნისთვის (კვირაში 30 სთ): kaggle.com → Settings → API → *Generate New Token*.
     GPU-სთვის Kaggle ტელეფონის ვერიფიკაციას ითხოვს.
   - **Hugging Face** — რეპოზიტორია (`mvarduka/aivoice-models`, ნაგულისხმევი) პირადია: ჩამოსატვირთად *Read* token
     და ავტორის მიცემული წვდომა (იხ. „დასაწყისი“), ასატვირთად — *Write*.
   - **Kaggle**-ის პირველ წვრთნაზე პანელი თქვენს ანგარიშზე თავად ქმნის დამხმარე dataset-ს (`aivoice-base2`:
     Piper-ის შესწორებები + LJSpeech checkpoint, ~800 MB, ერთხელ).
3. **მოდელები** — „⚙ პარამეტრები → მოდელები → ↓ ჩამოტვირთვა“ (ხმის შემქმნელი, ხმები, ნარევები, ~200 MB).
   ახალი ხმის მოსამზადებლად მონიშნეთ „+ საბაზო checkpoint-ები“ (~1.8 GB); საბაზოს გასაუმჯობესებლად —
   „+ ხარისხის მონაცემები“ (~4.5 GB: Common Voice-ის ჩანაწერები, CC0, და მათი ხარისხის ანალიზი). იგივე ბრძანებით:
   ```bash
   ./aivoice models pull [--base] [--data]
   ./aivoice models push [--base] [--data]   # თქვენი ახალი ხმები და ნარევები → საერთო რეპოზიტორია (Write token)
   ```

### ხმების ბიბლიოთეკა — „ხმები“
- თითო ხმას აქვს **ნორმა** (ტემპი, ინტონაცია, რიტმი, ხმამაღლობა). სლაიდერებით მოარგეთ → „💾 ნორმად შენახვა“; ემოციები მისგან ითვლება. „↺“ — წვრთნისდროინდელზე დაბრუნება.
- „რედაქტირება“: სახელი, სქესი, ასაკი, ხასიათი, სტატუსი (**მზადაა** / **სატესტო** / **დამალული**), წაშლა (ფაილები გადადის `trash/`-ში).
- **ტექსტი** გახმოვანებამდე სწორდება (`app/textnorm.py`): რიცხვები, თარიღები, დრო, ფასები (₾ $ €), პროცენტები, ერთეულები,
  „მე-5“, „XX საუკუნე“, „ქ.“, „ა.შ.“, „Google-ში“ → „გუგლში“. ტექსტის ქვეშ ჩანს, **როგორ წაიკითხავს**.
  **ლექსიკონი** („ხმები“ → „ლექსიკონი“) — ბრენდები და უცხო სიტყვები: დამატება, მოსმენა, წაშლა; Hugging Face-ით ზიარდება.
- **გრძელი ტექსტი → ფაილი**: ტექსტი ან .txt; აბზაცებს თავისი ხმა/ემოცია (ან ტექსტშივე `[სევდიანი]`, `[ქალი 1, მხიარული]`);
  პაუზები; შედეგი **MP3/WAV + SRT სუბტიტრები** (ზუსტი დროებით — ვიდეოსთვის/დუბლირებისთვის). API: `POST /api/longform`.
- ახლად გაწვრთნილი ან ჩამოტვირთული ხმა ჯერ **სატესტოა**. **„შემოწმება“**: ხმა და მისი ნარევი ერთსა და იმავე 8 ფრაზას კითხულობენ,
  ავტომატური მსმენელი (MMS) ორივეს აფასებს — მოუსმინეთ გვერდიგვერდ და დააჭირეთ **„✓ მზადაა“** ან „დამალვა“.
  წვრთნის ბოლოს შემოწმება თავისით ეშვება (`./aivoice check <id>`). „ქალი 1“: ხმა 10% · ნარევი 11%.

### განახლება
„⚙ პარამეტრები → განახლება“: ახალი ვერსიისას ჩანართზე ნიშანი ჩნდება; „განახლება და გადატვირთვა“ ჩამოტვირთავს კოდს,
საჭიროებისას ბიბლიოთეკებსაც, და პანელს თავიდან ჩატვირთავს. ბრძანებით: `./aivoice update` (შემოწმება), `./aivoice update apply`.
კოდის რეპოზიტორია საჯაროა — GitHub-ის ანგარიში განახლებისთვის საჭირო არ არის.

## ახალი ხმის შექმნა

### 1. ნარევი — „ხმის შემქმნელი“
- რუკაზე აირჩიეთ ხმები (მარცხნივ დაბალი, მარჯვნივ მაღალი) ან მზა ღილაკი („ნეიტრალური“, „ქალი“, „კაცი“).
- „ყველა ხმის მოსმენა“ — ყველა ხმა ზედიზედ კითხულობს ფრაზას; 👍 / 👎 (კლავიშები L / D).
- „რეიტინგი“ — ავტომატური მსმენელის (MMS) შეფასება: რაც ნაკლები შეცდომა, მით სუფთა ხმა.
- **ინტონაცია** ~0.3–0.5 — მშვიდი, სუფთა კითხვა (მაღალზე ხმა „კანკალებს“).
- უნიკალურობა < 0.8 — ნარევი არცერთ რეალურ ადამიანს არ ჰგავს.
- მოწონებული — **„შენახვა“** სახელით.

### 2. წვრთნა — „წვრთნა“ ჩანართი
1. **ახალი ხმა**: აირჩიეთ შენახული ნარევი, სახელი, ID (მაგ. `f_mix_02`) → „შექმნა“.
2. **მომზადება** (ამ კომპიუტერზე, ~1–2 სთ): ნარევი კითხულობს ~3000 წინადადებას; თითოეული 3-ჯერ, ავტომატური მსმენელი საუკეთესოს ირჩევს.
3. **გაშვება**: სად — **Kaggle** (რეკომენდებული, ~6 სთ, უფასოდ) ან **ეს კომპიუტერი** (CPU — დღეები).
4. პანელი თავად ელოდება და დასრულებისას ხმა ჩნდება **„ხმებში“**. „ლოგი“ აჩვენებს, რა ხდება.

იგივე ბრძანებებით:
```bash
./aivoice train new f_mix_02 --design "ქალი 2" --name "ქალი 2"
./aivoice train prepare f_mix_02
./aivoice train start f_mix_02 --on kaggle --wait
./aivoice train status
```

### საბაზო მოდელის შექმნა / გაუმჯობესება — „წვრთნა“ → „საბაზო მოდელი“
საბაზო მოდელი ასობით ადამიანის ხმაზე (Common Voice) ისწავლება; მისგან კეთდება ხმის შემქმნელი და ყველა ახალი ხმა.
1. **საიდან**: *გაგრძელება* (მაგ. `base_ka_v3` — ძველი ხმები უცვლელად რჩება, ემატება ახალი ჩანაწერები და ეპოქები) ან *ნულიდან*.
2. **ჩანაწერები**: ახალი შერჩევა (საათები + მოკლე ფრაზები / კითხვა-ძახილი / რთული ბგერები რ ღ ბ ფ პ) ან არსებული შერჩევა.
   გაგრძელებისას აირჩევა მხოლოდ ჯერ გამოუყენებელი ჩანაწერები. საჭიროა ხარისხის შემოწმება („მონაცემები → ხარისხი“).
3. **ეპოქები**: ნულიდან — სულ (~160), გაგრძელება — დამატებით (~90). პანელი აჩვენებს სავარაუდო დროს და ფასს.
4. **სად**: **Google Cloud** (L4, ≈ $0.9/სთ, ერთდროულად მხოლოდ ერთი წვრთნა; მანქანა დასრულებისას თავისით იშლება)
   ან **ეს კომპიუტერი** — მხოლოდ NVIDIA GPU-ით, ≥ 12 GB (Mac-ზე — მხოლოდ Google Cloud).
5. ბარათზე: **მომზადება** (dataset ამ კომპიუტერზე, 1–3 სთ) → **გაშვება** (1–4 დღე). დასრულებისას ახალი მოდელი ჩნდება „ხმის შემქმნელში“.

```bash
./aivoice base options                                        # რა შეიძლება: მოდელები, შერჩევები, GPU, Google Cloud
./aivoice base new base_ka_v4 --mode continue --from base_ka_v3 --hours 40 --short --punct --clusters --epochs 90
./aivoice base prepare base_ka_v4
./aivoice base start base_ka_v4 --on gcp                      # ან --on local
./aivoice base status base_ka_v4 · ./aivoice base stop base_ka_v4
```

### საკუთარი მონაცემები (Common Voice)
ხარისხის მონაცემების ნაცვლად (`models pull --data` — ავტორის წვდომით) შეგიძლიათ Common Voice 27 (ქართული, ~10.4 GB, CC0)
**თქვენი** ანგარიშით ჩამოტვირთოთ და საბაზო მოდელი თავად ააწყოთ.

> **პასუხისმგებლობა.** მონაცემები ჩამოიტვირთება **თქვენი** Mozilla Data Collective-ის ანგარიშით, Mozilla-ს Common Voice-ის
> პირობებით. მასში **ნამდვილი ადამიანების ხმებია**: დინამიკების ვინაობის დადგენა (ან ამის მცდელობა) **აკრძალულია**.
> ნამდვილ ხმებზე გაწვრთნილი მოდელები და მათი გამოყენება — მათ შორის ნამდვილი ადამიანის ხმის მიბაძვა, მოტყუება,
> თაღლითობა — **თქვენი პასუხისმგებლობაა**. პროექტის საჯარო მოდელებში მხოლოდ სინთეზური ხმებია.
> პირობები: [Mozilla Data Collective — Terms of Use](https://mozilladatacollective.com/terms) ·
> [Common Voice — პირობები](https://commonvoice.mozilla.org/terms) ·
> [მონაცემთა ნაკრების გვერდი](https://mozilladatacollective.com/datasets/cmu5x9qda00fenq07byl8rlc8).

1. **ანგარიში და გასაღები**: დარეგისტრირდით [mozilladatacollective.com](https://mozilladatacollective.com)-ზე, გახსენით
   [მონაცემთა ნაკრების გვერდი](https://mozilladatacollective.com/datasets/cmu5x9qda00fenq07byl8rlc8) და **დაეთანხმეთ მის
   პირობებს** (თორემ ჩამოტვირთვა „წვდომა უარყოფილია“-თი შეწყდება), შექმენით API key → პანელი → „პარამეტრები“ →
   „ანგარიშები“ → *Mozilla Data Collective API key*.
2. **ჩამოტვირთვა**: „მონაცემები“ → „ხარისხი“ → „Common Voice — ჩამოტვირთვა“ → მონიშნეთ პირობებზე თანხმობა →
   „ჩამოტვირთვა და ანალიზი“. ფონში მიდის (პანელის დახურვა არ აჩერებს), შეწყვეტისას იქიდან გრძელდება; დასრულებისას
   sha256 მოწმდება. შემდეგ არქივიდან ამოიღება ცხრილები (`validated.tsv`, `other.tsv` …) და კეთდება დინამიკების ანალიზი
   (`corpus.json`, საჭიროა `./install.sh --training`). mp3 არქივში რჩება. ადგილი: ≥ 11 GB `<sources>/cv27_ka/`-ში.
3. **ხარისხის შემოწმება**: იგივე გვერდზე „შემოწმების დაწყება“ (MMS + შიშინი/ხმაური; GPU-ით ~1–1.5 დღე, CPU-ზე გაცილებით მეტი) →
   დინამიკების გადარჩევა.
4. **საბაზო მოდელი**: „წვრთნა“ → „საბაზო მოდელი“ (იხ. ზემოთ) — შერჩევა → მომზადება → გაშვება.

```bash
./aivoice cv download --dry-run          # გეგმა: ზომა, ადგილი, რა უკვე არის (არაფერს წერს)
./aivoice cv download --check            # გასაღები და პირობებზე თანხმობა (არქივის ჩამოტვირთვის გარეშე)
./aivoice cv download --accept-terms     # ჩამოტვირთვა + ცხრილები + corpus.json (რაც არის — გამოტოვებს)
./aivoice quality                        # ხარისხის შემოწმება
```

### Google Cloud — საბაზო მოდელის წვრთნა
საჭიროა მხოლოდ საბაზო მოდელისთვის (ხმებისთვის — Kaggle, უფასოდ). **ფასიანია:** L4 GPU ≈ **$0.9/სთ** (on-demand,
აშშ-ის რეგიონები); გაგრძელება (~90 ეპოქა) ≈ 1–2 დღე, ნულიდან — 3–4 დღე. პანელი წინასწარ აჩვენებს სავარაუდო დროს და ფასს.
მანქანა **დასრულებისას თავისით იშლება**, უქმად დარჩენისას კი თავისით ითიშება (`gcp/autostop.sh`) — მაინც შეამოწმეთ
console.cloud.google.com → Compute Engine → VM instances, რომ ზედმეტი არაფერი დარჩეს.

1. **პროექტი**: [console.cloud.google.com](https://console.cloud.google.com) → ზედა მენიუ → *New project* (ID დაიმახსოვრეთ).
2. **ბილინგი**: *Billing* → ანგარიშის დამატება (ახალ ანგარიშს **$300 საცდელი კრედიტი** აქვს 90 დღით) → პროექტზე მიბმა.
   GPU-სთვის საცდელი ანგარიში ხშირად უნდა გადაიყვანოთ სრულზე (*Upgrade* — კრედიტი რჩება).
3. **API**: *APIs & Services → Library* → **Compute Engine API** → *Enable*.
4. **GPU კვოტა**: *IAM & Admin → Quotas* → მოძებნეთ და მოითხოვეთ **1**:
   „GPUs (all regions)“ (`GPUS_ALL_REGIONS`) და „NVIDIA L4 GPUs“ (`NVIDIA_L4_GPUS`) სასურველ რეგიონებში —
   `us-central1`, `us-east4`, `us-east1`, `us-west1` (იაფი), შემდეგ `europe-west4`. დასტური — წუთებიდან 1–2 დღემდე.
5. **gcloud**: [cloud.google.com/sdk/docs/install](https://cloud.google.com/sdk/docs/install) (macOS: `brew install --cask google-cloud-sdk`).
6. **შესვლა**: `gcloud auth login`
7. **პროექტი ნაგულისხმევად**: `gcloud config set project <პროექტის-ID>`
8. **პანელში**: „⚙ პარამეტრები → gcp“: *gcloud ბრძანება* (თუ PATH-ში არ არის, მაგ. `~/google-cloud-sdk/bin/gcloud`) და
   სურვილისამებრ *Google Cloud პროექტი* (თუ ცარიელია — მე-7 ნაბიჯისა). „შემოწმება“ აჩვენებს: gcloud, ანგარიში, პროექტი,
   Compute Engine API, L4 კვოტა (მხოლოდ კითხულობს — ფასიანი არაფერი ეშვება).

SSH გასაღები (`~/.ssh/aivoice_gcp`) პირველ გაშვებაზე იქმნება. L4 ხშირად ამოწურულია — მანქანა სხვა ზონაში თავად გადადის.

## რა ვისწავლეთ (მნიშვნელოვანი დეტალები)

- **„ს+ღ“** („ოდესღაც“) ცოცხალ მეტყველებაში „ხ“-ად ისმის — მოდელმაც ასე ისწავლა. ტექსტი გახმოვანებამდე ავტომატურად იწერება „ოდეს-ღაც“ (`app/textnorm.py`) და „ღ“ ისმის.
- **ემოციური კითხვა/ძახილი** ჯერ რობოტულად ჟღერს — Common Voice-ში ასეთი ინტონაცია ცოტაა. მშვიდი თხრობა კარგია.
- **ავტომატური მსმენელი (MMS)** „ღ“-ს ვერ აფასებს, მაგრამ შიშინს, კანკალს, ბუნდოვნებას და დაკარგულ ბგერებს კარგად იჭერს.
- **Kaggle:** კვოტა კვირაში 30 სთ; checkpoint ყოველ 2 ეპოქაში ინახება. **Google Cloud:** spot მანქანა შეიძლება შეწყდეს; L4 ხშირად ამოწურულია — მანქანა სხვა ზონაში გადადის. აშშ-ის ზონები ~2-ჯერ იაფია აზიაზე.
- **ერთი ხმის მოდელი იწყება ნარევით** — ნარევის ვექტორი საბაზო მოდელის წონებში „ჩაცხვება“ (`tools/fold_speaker.py`), ასე რომ წვრთნა პირველივე ნაბიჯიდან სწორი ხმით იწყება.
