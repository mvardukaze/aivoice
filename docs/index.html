ქართული სინთეზური ხმები

ღია, უფასო ქართული მეტყველების სინთეზი (Piper) — მუშაობს ჩვეულებრივ კომპიუტერზე, ინტერნეტის გარეშე. აქ ყველა ხმა სინთეზურია: რამდენიმე ხმის ნარევი, რომელიც არცერთ ნამდვილ ადამიანს არ ეკუთვნის.

მზა ხმები

ცალკე, მსუბუქი Piper-ის ხმები (~60 MB) — ჩამოტვირთეთ და გამოიყენეთ ნებისმიერ Piper-თან თავსებად პროგრამაში.

80 სინთეზური ხმა

ხმის შემქმნელის ბაზა: ბოხი კაცის ხმიდან მაღალ ქალის ხმამდე. ამათი შერევით პანელში ახალ ხმას აწყობთ და Kaggle-ზე უფასოდ წვრთნით.

გამოყენება

pip install piper-tts
# ჩამოტვირთეთ voices/f_mix_01/f_mix_01.onnx და .onnx.json (Hugging Face)
